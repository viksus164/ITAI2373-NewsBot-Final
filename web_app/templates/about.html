Project Overview

About NewsBot 2.0

A free local Flask frontend for the ITAI 2373 final project.

What this web app does

This frontend turns the notebook-based NewsBot into a browser application. A user can paste a news article and receive category prediction, confidence, sentiment, summary, named entities, discovered topic, keywords, and similar BBC articles.

Cost and APIs

This version does not use paid APIs. It trains lightweight local models from the BBC News Classification dataset and runs on a local Flask server.

Portfolio value

The web app demonstrates that the NLP pipeline can support a user-facing product, not only a notebook. This supports the final project's optional web application frontend bonus.
